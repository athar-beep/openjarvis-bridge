Apne account se login karo

Pehli dafa ho to "Naya account banao" dabao — ye tumhara owner account hoga. Sirf tumhari login se feed aur tasks nazar ayenge.

Agent ko task do

Task seedha nahi chalega — pehle Manzoori me ayega, pura text dobara dikhe ga, tumhara Approve milega tab hi agent chalega. Reject = task khatam. Bina manzoori ke task 10 minute me expire ho jata hai.

Kaam (fixed tasks)

Button dabane se request pehle Manzoori me jayegi. Tumhara Approve milega tab hi kaam chalega. Request 1 ghante me expire ho jati hai.

Manzoori (pending)

Koi pending request nahi.

Meri requests

Abhi koi request nahi bheji.

Feed — reports & digest

Feed khaali hai. Pehli report Nvidia Watch ya digest ke baad ayegi.

Sawal poochho (AI)

Sawal-jawab seedha cloud model se hota hai — is ke liye apni OpenRouter key ek dafa yahan dalo. Key sirf is phone me rehti hai, kahin aur nahi jati.
